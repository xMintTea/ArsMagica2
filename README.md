# Ars Magica 2-minted

A fork of **Ars Magica 2** for Minecraft **1.7.10**, maintained primarily for personal use - and for the love of the game.


## What's in this fork

- Bug fixes (see the commit history, closed issues and Releases)
- Personal balancing decisions of existing content
- No new content (*probably* not gonna change)

## Publishing and Usage

- I do **not** publish builds of this fork anywhere except the **Releases** on this GitHub page.
- I do **not** allow third parties to redistribute it — **ask first**. You can use the Issues for that.
- You **are** allowed to use builds of this fork in your game and on your servers. No need to ask.
